# Suffah Digital - Professional Online Quran Academy

Suffah Digital is a state-of-the-art, responsive, and SEO-friendly web application built with **Next.js 15** and **TypeScript**. It is designed specifically for online Islamic educational institutions, providing a premium user experience for students and an efficient management portal for administrators.

## 🌟 Key Features

- **Modern & Premium UI/UX**: A beautiful Emerald & Gold theme designed with custom CSS (no heavy frameworks like Tailwind) for maximum performance.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop views.
- **Course Catalog**: Detailed listing of Islamic courses including Tajweed, Hifz, Arabic, and Islamic Studies with professional iconography.
- **Online Admission System**: A streamlined registration process with real-time data persistence.
- **Admin Dashboard**: A secure portal (`/admin`) to manage admissions, view student statistics, and monitor academy growth.
- **Performance Optimized**: Built with Next.js App Router and optimized fonts/images for lightning-fast load times.
- **SEO Ready**: Comprehensive metadata and semantic HTML structure for high search engine visibility.

## 🚀 Technology Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Vanilla CSS with CSS Variables and Flex/Grid
- **Icons**: Custom SVG Professional Iconography
- **Fonts**: Google Fonts (Amiri for Arabic/Headings, Inter for Body)

## 📦 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/suffah-digital.git
   ```
2. Navigate to the project directory:
   ```bash
   cd suffah-digital
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
